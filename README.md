# Мультики (kidstube)

Детский клиент YouTube: показывает только видео с одобренных каналов, режет по стоп-словам,
плеер — официальный встроенный YouTube. Бесплатно, без своего сервера.

## Как получить APK (бесплатно, без установки Flutter)

1. Создай на github.com новый **приватный** репозиторий (например `kidstube`).
2. Загрузи в него ВСЁ содержимое этой папки (включая скрытую папку `.github`) — перетащи файлы в окно репозитория.
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `YT_API_KEY`
   - Secret: твой ключ YouTube Data API
4. Вкладка **Actions → Build APK → Run workflow**. Через ~5–8 минут внизу страницы запуска
   появится файл **kidstube-apk** (внутри `app-release.apk`).
5. Скачай, перекинь на телефон и установи (разреши установку из неизвестных источников).

## Родительский режим
Замок в правом верхнем углу → PIN (при первом входе придумать 4 цифры).
Там: включение/выключение каналов, добавление канала по @handle, свои стоп-слова,
блокировка видео, обновление ленты. Замок в плеере — заблокировать текущее видео или канал.

## Квота
Обновление ленты ≈ 2 единицы на канал, лимит 10 000/сутки — запас огромный.

# Версия для LG TV (webOS) и браузера

Состав: `web/` — сайт (работает на ТВ, в браузере, на телефоне), `webos/` — пакет-лаунчер для LG,
`.github/workflows/web-and-tv.yml` — публикация сайта на GitHub Pages + сборка `.ipk`.

## Один раз на GitHub
1. Репозиторий должен быть **публичным** (GitHub Pages бесплатен только для публичных). Секретов в коде нет.
2. Создай **второй** ключ YouTube Data API (Credentials → Create credentials → API key):
   - Application restrictions → **Websites** → добавь `https://ТВОЙ_ЛОГИН.github.io/*`
   - API restrictions → YouTube Data API v3
   (Ключ сайта виден всем, поэтому он обязательно ограничивается по адресу сайта. Ключ для APK — отдельный.)
3. Settings → Secrets and variables → Actions → секрет `YT_WEB_KEY` = этот второй ключ.
4. Settings → Pages → Source: **GitHub Actions**.
5. Actions → **Web + LG TV** → Run workflow. После выполнения:
   - сайт: `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПО/`
   - пакет для ТВ: артефакт **kidstube-webos-ipk** (файл `uz.kidstube.tv_1.0.0_all.ipk`).

## Установка на LG TV (режим разработчика, бесплатно)
1. На ПК: создай аккаунт на developer.lgwebos.com (бесплатно).
2. На ТВ: LG Content Store → установи **Developer Mode** → войди → Dev Mode Status = ON (ТВ перезагрузится) →
   снова открой приложение → включи **Key Server**. Запомни IP и passphrase на экране.
3. На ПК поставь **webOS Dev Manager** (github.com/webosbrew/dev-manager-desktop): Add Device → IP и passphrase →
   Apps → Install → выбери `.ipk`. Запусти «Мультики» на ТВ.
4. Режим разработчика на ТВ ограничен по времени — иногда нужно открыть Developer Mode и продлить сессию.

## Пульт
Стрелки — выбор, OK — открыть/пауза, Back — назад/выход из полного экрана, Play/Pause — пауза, ⏩⏪ — перемотка на 10 с.
Родительский режим: «Родителям» → PIN. В полноэкранном режиме: OK — пауза, ←/→ — перемотка, Back — выход.

## Telegram-бот: каналы без правки кода

Бот сам ищет новые детские каналы (мультики, английский с буквами, обучение, музыка/пианино), отсеивает по
пометке YouTube «сделано для детей» и стоп-словам и присылает вам карточку с кнопками ✅/❌.
Одобренный канал сам появляется на ТВ и в приложении (при следующем запуске или по кнопке «Обновить»).

Настройка (один раз), GitHub → репозиторий → Settings → Secrets and variables → Actions:

| Секрет | Что это |
|---|---|
| `TG_BOT_TOKEN` | токен бота из @BotFather |
| `TG_CHAT_ID` | ваш chat id (можно несколько через запятую, например с женой) |
| `YT_BOT_KEY` | отдельный ключ YouTube API БЕЗ ограничения по приложению/сайту (ограничьте только «YouTube Data API v3»); если не задан, берётся `YT_API_KEY` — он должен быть без ограничения по Android-приложению |

Дальше: Actions → «Telegram-бот» → Run workflow (дальше запускается сам каждые 5 минут и около 4 минут слушает кнопки,
поэтому ответ на нажатие приходит почти сразу). Напишите боту `/start`.

Команды (меню команд появится у бота само):
- `/search пианино для детей` — найти каналы по запросу, карточки с кнопками (до 40 поисков в сутки);
- `/channels` — все каналы кнопками: нажать на название = включить/выключить, 🏷 = сменить категорию, 🗑 = удалить;
- `/add @handle музыка` — добавить канал сразу (категории: мультики, английский, обучение, музыка), `/block @handle` — убрать;
- `/video ссылка` — заблокировать конкретное видео на всех устройствах;
- `/stop слово` и `/unstop слово` — свои стоп-слова для всех устройств;
- `/find` — искать новые каналы сейчас, `/status` — сводка, `/list` — что добавлено ботом.

Всё это хранится в `data/catalog.json`; приложения применяют изменения при запуске или по кнопке «Обновить».

Заметки:
- Каталог лежит в `data/catalog.json`, приложение читает его с raw.githubusercontent.com (репозиторий должен быть публичным).
- Поиск тратит квоту YouTube (около 450 из 10 000 единиц в сутки), бот делает его раз в сутки.
- Если GitHub отключит расписание после двух месяцев тишины, нажмите «Enable workflow» во вкладке Actions.
- Токен бота нигде не хранится в коде, только в секретах. Если он попал в переписку, перевыпустите: @BotFather → `/revoke`.

## Семьи (несколько родителей)

Один бот обслуживает много семей. Родитель пишет боту `/start` и получает код семьи (10 знаков, показывается один раз; потеряли или хотите сменить: `/newcode`). В приложении при первом входе в «Родителям» сначала спрашивается **«Ваша семья»**, и только после кода открываются настройки. Каталог семьи лежит в папке с хэшем кода (`data/families/<sha256(код)>/catalog.json`), так что самих кодов в репозитории не видно. У каждой семьи свой каталог каналов, свои стоп-слова и заблокированные видео. Приложение без кода показывает каталог владельца (`data/catalog.json`, код `main`).

Лимиты (защита квоты YouTube): не больше 30 семей, 8 поисков `/search` в день на семью, 60 в день на всех чужих. Автопоиск новых каналов по расписанию работает только у владельца (`TG_CHAT_ID`). Идентификаторы Telegram-чатов в репозиторий пишутся только в виде хэша.

_Публикация сайта: при сбое «No artifacts named github-pages» достаточно перезапустить workflow Web + LG TV._


## Детский режим

- Экран ребёнка без текста: крупные значки, ❤ «Любимое» (любимые идут первыми).
- Лимит времени и сон: в панели «Родителям → Время и сон» или в боте: `/limit 45`, `/bedtime 21:00`, `/name Имя`. Когда время вышло, показывается экран отдыха; продлить можно по PIN.
- Статистика «сегодня просмотрено» хранится только на устройстве (отчёт в Telegram без сервера невозможен).
- В Android-приложении кнопка «назад» на главной не выходит, режим полноэкранный.
